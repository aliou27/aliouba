Secure Microservices Architecture

A hands-on microservices project focused on securing distributed services with Keycloak, JWT, API Gateway and role-based access control.

← Back to selected work
01 / Architecture

Three JWT-protected Spring Boot services sit behind a Spring Cloud Gateway. Keycloak provides identity and roles, while Consul handles service discovery.

02 / Security

The gateway validates JWTs and relays tokens to downstream services. Services enforce USER and ADMIN authorization with Spring Security and Keycloak roles.

Java 21 · Spring Boot 3.2.5 · Spring Cloud Gateway · Keycloak · JWT · PostgreSQL · Docker · Consul

03 / Resilience

Routes use Resilience4j circuit breakers with fallback endpoints. The project also integrates Zipkin distributed tracing so requests crossing multiple services can be observed as a single trace.

04 / Validation

The architecture was exercised through authenticated reads, authorized and forbidden role-based operations, missing-token 401 responses and service-failure 503 fallback scenarios.
