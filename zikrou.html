Zikrou

A production mobile application for listening to Zikr and Waxtanes. I designed and built the product end to end, including the backend, REST API, database, authentication, infrastructure, storage and deployment.

← Back to selected work
01 / Product

Zikrou brings scattered audio content into one structured listening experience. It supports discovery by Zakir, Daira, Album and Genre, full-text search, favorites, history, follows, playlists, sleep timer and offline downloads.

02 / Engineering

Flutter clients connect to a Spring Boot REST API backed by PostgreSQL. The production stack runs with Docker Compose behind Caddy, while Cloudflare R2 and the CDN handle media storage and delivery.

Flutter · Riverpod · Spring Boot 4 · Java · PostgreSQL 17 · Flyway · Spring Security · JWT · Docker Compose · Caddy · Hetzner · Cloudflare R2

03 / Security

Authentication uses short-lived JWT access tokens and revocable UUID refresh tokens. The application uses BCrypt, role-based access control, HTTPS, validation, CORS controls and parameterized persistence queries.
